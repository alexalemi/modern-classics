Proposition V.21 (Theorem)

If *there be three magnitudes, and other three which have the same ratio, taken two and two, but in a cross order; then if the first magnitude be greater than the third, the fourth shall be greater than the sixth; and if equal, equal, and if less, less.*

Let ⟦g:051d⟧, ⟦g:0558⟧, ⟦g:0567⟧, be the first three magnitudes,

and ⟦g:0529⟧, ⟦g:0523⟧, ⟦g:0521⟧, the other three,

such that ⟦g:051d⟧ : ⟦g:0558⟧ :: ⟦g:0523⟧ : ⟦g:0521⟧ ,

and ⟦g:0558⟧ : ⟦g:0567⟧ :: ⟦g:0529⟧ : ⟦g:0523⟧ .

Then if ⟦g:051d⟧ >, =, or < ⟦g:0567⟧ ,

then will ⟦g:0529⟧ >, =, or < ⟦g:0521⟧ .

First, let ⟦g:051d⟧ be > ⟦g:0567⟧ :

then, because ⟦g:0558⟧ is any other magnitude,

⟦g:051d⟧ : ⟦g:0558⟧ > ⟦g:0567⟧ : ⟦g:0558⟧ (prop. V.8);

but ⟦g:0523⟧ : ⟦g:0521⟧ :: ⟦g:051d⟧ : ⟦g:0558⟧ (hyp.);

∴ ⟦g:0523⟧ : ⟦g:0521⟧ > ⟦g:0567⟧ : ⟦g:0558⟧ (prop. V.13);

and ∵ ⟦g:0558⟧ : ⟦g:0567⟧ :: ⟦g:0529⟧ : ⟦g:0523⟧ (hyp.);

∴ ⟦g:0567⟧ : ⟦g:0558⟧ :: ⟦g:0523⟧ : ⟦g:0529⟧ (invert.),

and it was shown that ⟦g:0523⟧ : ⟦g:0521⟧ > ⟦g:0567⟧ : ⟦g:0558⟧ , ∴ ⟦g:0523⟧ : ⟦g:0521⟧ > ⟦g:0523⟧ : ⟦g:0529⟧ (prop. V.13);

∴ ⟦g:0521⟧ < ⟦g:0529⟧ ,

Secondly, let ⟦g:051d⟧ = ⟦g:0567⟧ ; then shall ⟦g:0529⟧ = ⟦g:0521⟧ .

but ⟦g:051d⟧ : ⟦g:0558⟧ = ⟦g:0523⟧ : ⟦g:0521⟧ (hyp.),

and ⟦g:0567⟧ : ⟦g:0558⟧ = ⟦g:0523⟧ : ⟦g:0529⟧ (hyp. and invert.),

∴ ⟦g:0523⟧ : ⟦g:0521⟧ = ⟦g:0523⟧ : ⟦g:0529⟧ (prop. V.11),

∴ ⟦g:0529⟧ = ⟦g:0521⟧ (prop. V.9).

Next, let ⟦g:051d⟧ be < ⟦g:0567⟧ , then ⟦g:0529⟧ shall be < ⟦g:0521⟧ ;

for ⟦g:0567⟧ > ⟦g:051d⟧ ,

and it has been shown that ⟦g:0567⟧ : ⟦g:0558⟧ = ⟦g:0523⟧ : ⟦g:0529⟧ ,

and ⟦g:0558⟧ : ⟦g:051d⟧ = ⟦g:0521⟧ : ⟦g:0523⟧ ;

∴ by the first case ⟦g:0521⟧ is > ⟦g:0529⟧ ,

that is, ⟦g:0529⟧ < ⟦g:0521⟧ .
