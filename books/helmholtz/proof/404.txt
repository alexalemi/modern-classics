The integral of equation (1) may also, as is well known, be exhibited in the following form:— \[y = \phi(x - at) + \psi(x + at) \tag{4}\] where \(a^2 = \frac{T}{\mu}\), and \(\phi\), \(\psi\) are arbitrary functions. The function \(\phi(x - at)\) denotes any form of the string which advances in the direction of positive \(x\) with the ¶ velocity \(a\), but without any other change; and the function \(\psi(x + at)\) denotes a similar form proceeding with the same velocity in the direction of negative \(x\). For any given value of the time \(t\) we must suppose both functions to be given from \(x = - \infty\) to \(x = + \infty\), and then the motion of the string is determined.

The determination of the motion of a plucked string will result in this second form of solution, from determining the functions \(\phi\) and \(\psi\), so that

1) for the values \(x = 0\) and \(x = l\), the value of \(y\) for any value of \(t\) will be constantly \(= 0\). This will be the case, if for any value of \(t\), \[\phi( - at) = - \psi( + at) \tag{4a}\] and \[\phi(l - at) = - \psi(l + at) \tag{4b}\]

If in the first equation we put \(at = - v\), and in the second \(l + at = - v\), we obtain \[\phi(v) = - \psi( - v)\] ¶ and \[\phi(2l + v) = - \psi( - v)\] so that \[\phi(2l + v) = \phi(v) \tag{5}\]

Hence the function \(\phi\) is periodic, for its value becomes the same when its argument is increased by \(2l\). The same results for \(\psi\).

2) For \(t = 0\), we must have \(\frac{dy}{dt} = 0\) between the limits \(x = 0\) and \(x = l\). Hence writing \(\psi'(v)\) for \(\frac{d\psi(v)}{dv}\), and putting \(\frac{dy}{dt} = 0\) in equation (4), we obtain \[\phi'(x) = \psi'(x)\]

And integrating this with respect to \(x\), we have \[\phi(x) = \psi(x) + C\]

¶ Now since neither \(y\) nor \(\frac{dy}{dt}\) are altered by adding the same constant to \(\phi\) and subtracting it from \(\psi\), the constant \(C\) is perfectly arbitrary, and we may consequently assume it to be \(= 0\), and hence write \[\phi(x) = \psi(x) \tag{5a}\]
