Appendix III: On the Motion of Plucked Strings

{¶374d}(See p. {@52b|52b}.)

Let \(x\) be the distance of a point in the string from one of its extremities, and \(l\) the length of the string, so that for one extremity \(x = 0\), and for the other \(x = l\). It is sufficient to investigate the case for which the motion takes place in one plane passing through the position of rest. Let \(y\) be the distance of the point \(x\) from its position of rest at the time \(t\). And let \(\mu\) be the weight of the unit {¶375}of length, and \(T\) the tension of the string. The differential equation of motion is then \[\mu \,.\, \frac{d^2y}{dt^2} = T \,.\, \frac{d^2y}{dx^2} \tag{1}\]

Then, since the extremities of the string are assumed to be at rest, we must have \[y = 0 \text{ when } x = 0, \text{ and also when } x = l \tag{1a}\]

The most general integral of the equation (1) which fulfils the conditions (1a) and corresponds to a periodic motion of the string, is {¶375b}\[\left.\begin{aligned} y = {} & A_1 \,.\, \sin\frac{\pi x}{l} \,.\, \cos 2\pi nt + A_2 \,.\, \sin\frac{2\pi x}{l} \,.\, \cos 4\pi nt \\ & + A_3 \,.\, \sin\frac{3\pi x}{l} \,.\, \cos 6\pi nt + \&c. \\ & + B_1 \,.\, \sin\frac{\pi x}{l} \,.\, \sin 2\pi nt + B_2 \,.\, \sin\frac{2\pi x}{l} \,.\, \sin 4\pi nt \\ & + B_3 \,.\, \sin\frac{3\pi x}{l} \,.\, \sin 6\pi nt + \&c. \end{aligned}\right\} \tag{1b}\] where \(n^2 = \frac{T}{4\mu l^2}\) and \(A_1, A_2, A_3\), &c., and \(B_1, B_2, B_3\), &c., are any constant coefficients, which can be determined when the form and velocity of the string are known for any determinate time \(t\).

For \(t = 0\), the form of the string will be \[y = A_1 \,.\, \sin\frac{\pi x}{l} + A_2 \,.\, \frac{\sin 2\pi x}{l} + A_3 \,.\, \sin\frac{3\pi x}{l} + \&c. \tag{1c}\] and the velocity of the string will be {¶375c}\[\frac{dy}{dt} = 2\pi n \left(B_1 \,.\, \sin\frac{\pi x}{l} + 2B_2 \,.\, \sin\frac{2\pi x}{l} + 3B_3 \,.\, \sin\frac{3\pi x}{l} + \&c.\right) \tag{1d}\]

Now suppose the string to have been drawn aside by a sharp point, and that the point was withdrawn at the time \(t = 0\), so that the vibration commenced at that moment, then for \(t = 0\) there was no velocity, that is \(\frac{dy}{dt}\) was \(= 0\) for all values of \(x\). This can only be the case when in equation (1d), \(0 = B_1 = B_2 = B_3 = \&c.\)

The coefficients \(A_1, A_2, A_3\), &c., depend on the shape of the string at the time \(t = 0\). At the moment the sharp point quitted it the string must have assumed the position of fig. 18 A (p. {@54|54a}), that is, it must have formed two straight lines proceeding from the sharp point to the fixed extremities of the string. Supposing the position of the sharp point at that moment to be determined by \(x = a\) and \(y = b\), then for the time \(t = 0\), the value of \(y\), was \[y = \frac{bx}{a} \text{ if } a > x > 0 \tag{2}\] {¶375d}\[\text{and } y = b \,.\, \frac{l - x}{l - a} \text{ if } l > x > a \tag{2a}\] and the values of \(y\) in (1c) and (2), or else (2a) respectively, must be identical.

To find the coefficient \(A_m\), the well-known method is to multiply both sides of the equation (1c) by \(\sin\frac{m\pi x}{l} \,.\, dx\), and to integrate between the limits \(x = 0\) and \(x = l\). In this case equation (1c) reduces to \[\int_0^l y \,.\, \sin\frac{m\pi x}{l} \,.\, dx = A_m \,.\, \int_0^l \sin^2\frac{m\pi x}{l} \,.\, dx \tag{2b}\] in which \(y\) must be replaced by its values in (2) and (2a). Performing the integrations indicated in (2b) we find \[A_m = \frac{2bl^2}{m^2\pi^2 a(l - a)} \,.\, \sin\frac{m\pi a}{l} \tag{3}\] {¶376}Hence \(A_m\) will \(= 0\), and consequently the *m*th tone of the string will disappear when \(\sin\frac{m\pi a}{l} = 0\), that is, when \(a = \frac{l}{m}\) or \(= \frac{2l}{m}\), or \(= \frac{3l}{m}\), &c. Hence we suppose the string to be divided into *m* equal parts, and to be plucked in one of these divisions, the *m*th tone disappears, and this is the tone whose nodes fall upon these points.

Every node for an *m*th tone is also a node for the \(2m\)th, \(3m\)th, \(4m\)th, &c., tone, and hence all these tones also disappear.

The integral of equation (1) may also, as is well known, be exhibited in the following form:— \[y = \phi(x - at) + \psi(x + at) \tag{4}\] where \(a^2 = \frac{T}{\mu}\), and \(\phi\), \(\psi\) are arbitrary functions. The function \(\phi(x - at)\) denotes any form of the string which advances in the direction of positive \(x\) with the {¶376b}velocity \(a\), but without any other change; and the function \(\psi(x + at)\) denotes a similar form proceeding with the same velocity in the direction of negative \(x\). For any given value of the time \(t\) we must suppose both functions to be given from \(x = - \infty\) to \(x = + \infty\), and then the motion of the string is determined.

The determination of the motion of a plucked string will result in this second form of solution, from determining the functions \(\phi\) and \(\psi\), so that

1) for the values \(x = 0\) and \(x = l\), the value of \(y\) for any value of \(t\) will be constantly \(= 0\). This will be the case, if for any value of \(t\), \[\phi( - at) = - \psi( + at) \tag{4a}\] and \[\phi(l - at) = - \psi(l + at) \tag{4b}\]

If in the first equation we put \(at = - v\), and in the second \(l + at = - v\), we obtain \[\phi(v) = - \psi( - v)\] {¶376c}and \[\phi(2l + v) = - \psi( - v)\] so that \[\phi(2l + v) = \phi(v) \tag{5}\]

Hence the function \(\phi\) is periodic, for its value becomes the same when its argument is increased by \(2l\). The same results for \(\psi\).

2) For \(t = 0\), we must have \(\frac{dy}{dt} = 0\) between the limits \(x = 0\) and \(x = l\). Hence writing \(\psi'(v)\) for \(\frac{d\psi(v)}{dv}\), and putting \(\frac{dy}{dt} = 0\) in equation (4), we obtain \[\phi'(x) = \psi'(x)\]

And integrating this with respect to \(x\), we have \[\phi(x) = \psi(x) + C\]

{¶376d}Now since neither \(y\) nor \(\frac{dy}{dt}\) are altered by adding the same constant to \(\phi\) and subtracting it from \(\psi\), the constant \(C\) is perfectly arbitrary, and we may consequently assume it to be \(= 0\), and hence write \[\phi(x) = \psi(x) \tag{5a}\]

3 Since finally at the time \(t = 0\), and within the limits \(x = 0\), \(x = l\), the magnitude \[y, \text{ which is } = \phi(x) + \psi(x) = 2\phi(x),\] must have the value shewn in fig. 18 A (p. {@54|54a}), the ordinates of this figure immediately give the value of \(2\phi(x)\) and of \(2\psi(x)\), by means of equation (5):—

	between | \(x = 0\) | and | \(x = l\)
	,, | \(x = 2l\) | ,, | \(x = 3l\)
	,, | \(x = 4l\) | ,, | \(x = 5l\)

and so forth.

{¶377}But since from (4a, 4b, 5) it follows that \(\phi( - v) = - \phi(v)\), and \(\phi(l - v) = - \phi(l + v)\), the value of \(2\phi(x)\) is given by the triangle in fig. 18 G. (p. {@54b|54b}),

	between | \(x = - l\) | and | \(x = 0\)
	,, | \(x = - 3l\) | ,, | \(x = - 2l\)
	and in the same way between | \(x = l\) | ,, | \(x = 2l\)
	,, | \(x = 3l\) | ,, | \(x = 4l\)

and so forth.

By this means the functions \(\phi\) and \(\psi\) are completely determined, and on supposing that the two wave-lines proceed in opposite directions with the velocity \(a\), we obtain the forms of the string given in fig. 18, p. {@54|54a}, {@54b|b}, which represent the changes of the string for every twelfth part of the periodic time of its vibration.
