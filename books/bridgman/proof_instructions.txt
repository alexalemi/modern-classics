MATHEMATICS (the reason this pass exists)
- Every formula, symbol, subscript, exponent or dimensional expression is
  LaTeX. Inline: \( ... \). Displayed (set on its own line, centred): \[ ... \]
  written INSIDE the paragraph line where it falls, with the text before and
  after it on the same line. If a displayed formula ends a paragraph, the
  paragraph ends after the \].
- Standard LaTeX only (amsmath is available): \frac, ^{}, _{}, \sqrt, \Pi,

- Single letters in running text that are symbols are maths: "the units L,

  display with \tag{}: \[ F = ma \tag{3} \].
- A multi-line display (a system of equations, aligned steps): one \[ \]
  with \begin{aligned} ... \\ ... \end{aligned}.
- Copy exponents and coefficients EXACTLY. Every number is a measured or
  derived value and a wrong digit reads perfectly.
- A TABLE of symbols or values: one row per line, each line starting with a
  TAB, cells separated by " | ", maths inside cells as \( \).
