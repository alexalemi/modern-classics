Proposition VI.22 (Theorem)

[Figure aho: The diagram for Proposition VI.22, in Byrne’s colours.]

If *four straight lines be proportional (* ⟦g:0343⟧ : ⟦g:01c8⟧ :: ⟦g:0008⟧ : ⟦g:000d⟧ *), the similar rectilinear figures similarly described on them are also proportional.And if four similar rectilinear figures, similarly described on four straight lines, be proportional, the straight lines are also proportional.*

 Part I.

Take ⟦g:0647⟧ a third proportional to ⟦g:0343⟧ and ⟦g:01c8⟧, and ⟦g:017f⟧ a third proportional to ⟦g:0008⟧ and ⟦g:000d⟧ (prop. VI.11);

since ⟦g:0343⟧ : ⟦g:01c8⟧ :: ⟦g:0008⟧ : ⟦g:000d⟧ (hyp.)

⟦g:01c8⟧ : ⟦g:0647⟧ :: ⟦g:000d⟧ : ⟦g:017f⟧ (const.)

∴ ex æquali,

⟦g:0343⟧ : ⟦g:0647⟧ :: ⟦g:0008⟧ : ⟦g:017f⟧ ;

but ⟦g:0648⟧ : ⟦g:0649⟧ :: ⟦g:0343⟧ : ⟦g:0647⟧ (prop. VI.20),

and ⟦g:064a⟧ : ⟦g:064b⟧ :: ⟦g:0008⟧ : ⟦g:017f⟧ ;

∴ ⟦g:0648⟧ : ⟦g:0649⟧ :: ⟦g:064a⟧ : ⟦g:064b⟧ (prop. V.11).

 Part II.

Let the same construction remain;

⟦g:0648⟧ : ⟦g:0649⟧ :: ⟦g:064a⟧ : ⟦g:064b⟧ (hyp.),

∴ ⟦g:0343⟧ : ⟦g:0647⟧ :: ⟦g:0008⟧ : ⟦g:017f⟧ (const.),

and ∴ ⟦g:0343⟧ : ⟦g:01c8⟧ :: ⟦g:0008⟧ : ⟦g:000d⟧ (prop. V.11).

Q. E. D.
